# Vehicle Make Logo Sources

Logo digunakan hanya untuk membantu pelanggan mengenali pilihan merek pada
form kendaraan. Seluruh nama dan merek dagang tetap milik pemegang merek
masing-masing.

Daftar merek aktif mengacu pada daftar passenger vehicle GIIAS 2026 yang
diterbitkan GAIKINDO dan daftar anggota GAIKINDO:

- <https://www.gaikindo.or.id/en/various-new-car-brands-to-join-the-giias-2026-2/>
- <https://www.gaikindo.or.id/anggota/>

Sumber aset:

- AION, BYD, Chery, Daihatsu, Isuzu, Wuling, dan XPeng berasal dari featured
  image profil anggota GAIKINDO.
- Audi, BMW, Citroën, Ford, Honda, Hyundai, Jeep, Kia, Mazda, MG, MINI,
  Mitsubishi, Nissan, Subaru, Suzuki, Toyota, Volkswagen, dan Volvo diraster
  dari Simple Icons 16.27.1. Metadata Simple Icons menunjuk ke sumber resmi
  masing-masing merek; paket didistribusikan di bawah CC0-1.0.
- BAIC, Geely, GWM, Jetour, dan Lexus diraster dari berkas logo Wikimedia
  Commons yang menyatakan public-domain/simple-geometry atau text-logo.
- Mercedes-Benz, VinFast, dan DFSK memakai fallback mark lokal agar seluruh
  pilihan tetap memiliki visual ketika sumber resmi tidak menyediakan asset
  raster yang stabil untuk proses build.

Jangan hotlink asset sumber dari aplikasi. File lokal ini menjaga tampilan
picker tetap stabil dan dapat di-cache oleh client.
